# Evidencias de ceremonias · Sprint 3

Actas editables del Sprint 3. Los campos con hechos del repositorio (issues, PR, fechas de fusión) ya están llenos; el equipo debe reemplazar los `PENDIENTE` y enlazar la evidencia real antes del cierre. No registrar datos sensibles, credenciales ni datos de candidatos.

| Archivo            | Uso                                     |
| ------------------ | --------------------------------------- |
| `planning.md`      | Planeación y objetivo del Sprint        |
| `refinamiento.md`  | Aclaraciones y cambios del backlog      |
| `dailies.md`       | Registro acumulado de reuniones diarias |
| `review.md`        | Demostración, feedback y aceptación     |
| `retrospectiva.md` | Aprendizajes y acciones de mejora       |

Resumen y checklist de cierre: [`docs/wiki/36-Sprint-3-Ceremonias-y-cierre.md`](../../wiki/36-Sprint-3-Ceremonias-y-cierre.md).
