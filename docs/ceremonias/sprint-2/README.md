# Evidencias de ceremonias · Sprint 2

Periodo documental solicitado: **9 de septiembre a 15 de octubre de 2026**.

Estas actas separan tres tipos de información:

- **Verificada:** proviene de commits, pull requests, CI, issues o pruebas reproducibles.
- **Reconstruida:** resume decisiones visibles en el producto y debe ser ratificada por el equipo.
- **Pendiente:** requiere fecha real, asistentes, comentarios o evidencia aportada por quienes participaron.

No se asignaron reuniones a fechas ficticias. La actividad funcional del Sprint 2 quedó integrada en GitHub el **20 de octubre de 2026**, después del intervalo solicitado. Por eso, el intervalo sirve como marco del Sprint, pero no como prueba de que una ceremonia ocurrió.

| Archivo            | Uso                                              | Estado                                       |
| ------------------ | ------------------------------------------------ | -------------------------------------------- |
| `planning.md`      | Objetivo, alcance, capacidad y compromisos       | Borrador para ratificación                   |
| `dailies.md`       | Bitácora verificable y formato para notas reales | Evidencia de repositorio; Dailies pendientes |
| `refinamiento.md`  | Criterios, dependencias y decisiones de alcance  | Reconstruido; ratificación pendiente         |
| `review.md`        | Guion de demostración y decisión del PO          | Listo para realizar                          |
| `retrospectiva.md` | Hallazgos y acciones de mejora                   | Borrador para realizar                       |

Para convertir cada archivo en evidencia formal, el equipo debe completar los campos `POR CONFIRMAR`, adjuntar una captura, grabación o acta autorizada y registrar la decisión del Product Owner por historia.
